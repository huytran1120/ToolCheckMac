Engineered for Deep Hardware Inspection

Built directly on low-level Apple frameworks: IOKit, CoreWLAN, system_profiler, and Metal.

🛡️

Anti-Tamper Serial Verification

Cross-references low-level IOKit kernel structures with system_profiler outputs to detect firmware-level spoofing or modified identifiers.

🔋

True Battery Health & Cycles

Reads raw cycle count, factory design capacity vs. current maximum capacity, battery temperature, and charging circuitry metrics directly via IORegistry.

🔒

Enterprise MDM & Lock Detection

Detects hidden Apple Business/School Manager (DEP) MDM profiles, Find My Mac, and iCloud Activation Lock risks before transaction.

💾

NVMe SSD Health & SMART

Scans internal solid-state drive SMART health status, Total Bytes Written (TBW), power-on hours, unsafe shutdowns, and spare block headroom.

⚡

Performance & Disk Benchmark

Real-time disk throughput testing bypassing OS cache (`F_NOCACHE`), coupled with a multi-core CPU thermal throttling stress monitor.

📊

Diagnostic Reports Export

Export elegant, branded diagnostic reports in high-resolution PNG or PDF with a single click. Keep historical snapshots to track wear over time.

Interactive Hardware Diagnostic Suite

Step-by-step interactive verification tests for all physical components:

✓ Keyboard Matrix: Visual keys light up instantly upon press to spot stuck keys.
✓ Fullscreen Display: Solid black, white, RGB primaries & gradients to catch dead pixels.
✓ Audio Stereo Sweep: Isolated left & right channel playback to test speaker balance.
✓ Microphone Monitor: Real-time RMS decibel level meter without saving audio.
✓ Camera Sensor: Live sensor preview to verify webcam resolution and optics.
✓ Biometric Touch ID: Native LocalAuthentication prompt to verify biometric sensor.
✓ Trackpad Force Touch: Canvas drawing with gesture recognizers & pressure gauge.
✓ Port Live Plug/Unplug: Real-time differential bus detection for USB & Thunderbolt ports.

Quick Installation Guide

How to install and run ToolCheckMacBook on macOS:

1

Download DMG

Download the latest ToolCheckMacBook.dmg disk image installer.

2

Drag to Applications

Open the DMG file and drag ToolCheckMacBook.app into your Applications folder.

3

Open the App

Right-click (Control-click) ToolCheckMacBook.app and select Open if macOS prompts developer verification.
